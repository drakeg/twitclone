# Ripple branding

The user-facing product name is **Ripple**.

The repository and Python package are still named `twitclone` to preserve stable
imports, deployment commands, migration history, and repository links. Treat
those values as implementation identifiers rather than product branding.

New user-facing templates, documentation, page metadata, and accessible labels
should use Ripple unless they are explicitly describing the legacy repository or
Python package name.
